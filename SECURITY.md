# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of ClashMate users very seriously.
If you discover a security vulnerability or sensitive data exposure, please email **security@clashmate.io** instead of opening a public issue.

Include:
- Type of vulnerability
- Step-by-step reproduction instructions
- Potential impact

We will respond promptly and coordinate a patch before disclosure.
